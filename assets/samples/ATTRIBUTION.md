# Khronos glTF sample assets

These eight unmodified GLB files come from [KhronosGroup/glTF-Sample-Assets](https://github.com/KhronosGroup/glTF-Sample-Assets) at commit `edc7c9e67c639d230715049ee31f9a96a6babbbe`. Each `README.upstream.md` is copied from that model's directory and records its credits and license. The files provide examples of glTF features; inclusion does not imply the engine supports every feature shown.

| Model | glTF feature | License summary |
| --- | --- | --- |
| Box | Geometry without a texture | CC BY 4.0, Cesium |
| Lantern | Several meshes and embedded textures | CC0, Microsoft and Frank Galligan |
| ToyCar | Several meshes, materials, and PBR textures | CC0, Public |
| AlphaBlendModeTest | Opaque, masked, and blended materials | CC BY 4.0, Analytical Graphics, Inc. |
| CesiumMan | Skin and animation | CC BY 4.0, Cesium; see upstream logo notice |
| AnimatedMorphCube | Two animated morph targets | CC0, Microsoft |
| MorphPrimitivesTest | Multiple primitives and morph targets | CC BY 4.0, ft-lab and Frank Galligan |
| InterpolationTest | Translation/rotation/scale clips with STEP, LINEAR, and CUBICSPLINE interpolation | CC0, Khronos |

All eight GLBs were checked against the upstream Git blob hashes before inclusion. See the upstream README beside each model for full credit and terms. For `CesiumMan`, the upstream Cesium logo notice is retained in `LICENSES/LicenseRef-LegalMark-Cesium.txt`.

`InterpolationTest/InterpolationTest.glb` is 7,952 bytes; verified upstream Git
blob `4200fccc95261f36bf8af58e99f3180968333714`, SHA-256 `a86eb331b4a083715e75fe19a1f747eac5692d5b9ff120f1eaa457c23ba72bca`.

The four models in `../physics/` are recolored derivatives of Cesium's Box
(CC BY 4.0): Platform, BlueBox, YellowBox, and GreenBox. Only material base colors
were changed. Source, credits, and license are retained in
[Box's upstream README](Box/README.upstream.md).

ThinPlatform, ThinWallBlue, and ThinWallGreen in `../physics/` are additional
Box derivatives under the same CC BY 4.0 license, with flattened node transforms
and changed material colors. YellowSphere is procedural geometry created for
this repository. These four assets are generated by
[generate-physics-shapes.py](../../tools/generate-physics-shapes.py).

`../physics/RingRamp.glb` is original procedural geometry generated by
`tools/generate-physics-shapes.py` in this repository, under the repository license.

`AnimatedMorphCube/AnimatedMorphCube.glb` is 6752 bytes, from the same pinned upstream commit; Git blob `219d2ac524060e34f13d1253729f563cf76aca97`, SHA-256 `214ee56160a50dbf22543a1d66dbf860986e87f0efac3d89feac1359d0e6aeab`.
